1. PROJECT OVERVIEW & EXECUTIVE SUMMARY
================================================================================

Brick Factory is a professional-grade, web-based civil engineering estimation, 
3D architectural modeling, and construction material management platform built 
for A V M Bricks (a premier brick manufacturing enterprise based in Dindigul, Tamil Nadu).

Traditional construction estimation relies on fragmented manual calculations, 
rough rules of thumb, and disconnected spreadsheets. This frequently results in:
  - Inaccurate material orders (causing site stoppages or expensive surplus waste).
  - Unaccounted corner overlaps and structural member collisions.
  - Blind estimation without visual 3D verification of doors, windows, and columns.
  - Separation between structural RCC framing (columns, beams, slabs, footings) 
    and masonry infill calculations.
  - Inability for builders and homeowners to save, edit, and share building plans.

Brick Factory solves these challenges comprehensively by providing:
1. Interactive 2D Architectural Plan Canvas:
   - Interactive wall drawing with millimeter-accurate snapping.
   - Dynamic door, window, and ventilator openings placement.
   - RCC column / pillar placement with coordinate snapping and custom sections.
   - Multi-floor building support (Ground Floor, Floor 1, Floor 2, Floor 3, etc.).
   - Isolated foundation and footing design mode.
   - Surface-by-surface wall and ceiling plastering configuration.

2. Real-Time WebGL 3D Visualization Engine (Three.js & React Three Fiber):
   - 60 FPS hardware-accelerated rendering utilizing Three.js `InstancedMesh`.
   - Zero Masonry Collision: Automatic wall splitting around concrete columns (`splitWallByPillars`).
   - Additive multi-floor stacking with zero-gap column and beam interfaces.
   - Dual-mode framing: Open-top RCC Ring Beams vs Closed RCC Full Ring Beam slabs.
   - Exposed Rebar Inspection Mode (X-Ray translucent concrete with high-contrast steel cages):
     * Vertical pillar reinforcement cages with main longitudinal bars and closed stirrups.
     * 3-tier beam-column confining joint ties.
     * Horizontal two-way orthogonal slab reinforcement mesh (main + distribution bars).
     * Isolated trapezoidal foundation footings with bottom rebar mesh mats and column stubs.
   - Multi-view camera presets (Orbit, Isometric, Front, Side, Top, Wireframe, Collision Debug).

3. Civil Engineering Mathematical Calculation Engine:
   - Exact volume deductions for openings, lintels, and structural columns.
   - Default Tamil Nadu Standard Red Clay Brick (230 × 115 × 75 mm) specification.
   - Multi-floor itemized brick count (base count, wastage factor, recommended purchase).
   - Mortar mix ratios (1:3, 1:4, 1:5, 1:6) with dry conversion factor (1.33).
   - Plastering calculations conforming to IS 1200 opening deduction standards.
   - RCC concrete volumetric mix formulas (M20, M15, M10 with dry factor 1.54).
   - Steel reinforcement weight calculations using standard formula: Weight = D² / 162.
   - Foundation earthwork excavation, PCC 1:4:8 base, RCC footings, and backfilling.
   - Daily labor productivity and wage calculations (masons and helpers).

4. Cloud Project Persistence & History Management:
   - Full PostgreSQL cloud database integration via Prisma ORM (`SavedProject` model).
   - Dual-storage architecture: Saves to PostgreSQL with transparent LocalStorage offline fallback.
   - Dedicated Save Modal and Project History Manager for instant reload of past designs.

5. Complete E-Commerce, Product Catalog & B2B Inquiry Portal:
   - Full product catalog with technical parameters (Compressive Strength, Water Absorption, Density).
   - Direct B2B bulk quotation system with automated Nodemailer email notifications.
   - Direct WhatsApp quote integration connecting customers to A V M Bricks sales reps.

[MODULE 1] 2D INTERACTIVE ARCHITECTURAL CANVAS & BUILDING EDITOR
(Location: src/components/calculator/BuildingEditor.tsx)
--------------------------------------------------------------------------------
The Building Editor provides a CAD-style browser canvas with three dedicated modes:

A. Floor Plan Mode (`activeMode === 'floor'`):
   - Wall Drawing Tool:
     * Click-to-start and click-to-finish wall segment placement.
     * Real-time grid snapping, orthogonal alignment, and length/thickness previews.
     * Custom wall thickness presets (4.5" partition wall, 9" load-bearing wall, custom mm/in/ft).
     * Distinction between External Perimeter Walls and Internal Partition Walls.
   - Openings Placement Tools:
     * Doors (Main Entrance 3.5'×7', Standard 3'×7', Bathroom 2.5'×7', custom).
     * Windows (4'×4', 5'×4', 3'×4', custom).
     * Ventilators (2'×1.5', custom).
     * Interactive drag along wall edges with live offset indicator.
   - RCC Pillars / Columns Tool:
     * Rectangular (9"×9", 9"×12", 12"×12") or Circular column profiles.
     * Corner snapping to wall intersections or free grid placement.
     * Column height configuration (inherits floor height by default).
   - RCC Ring Beam Configuration:
     * Mode A (Perimeter Ring Beam): Adds beam height (e.g. +2 ft) around perimeter, top remains OPEN.
     * Mode B (RCC Full Ring Beam): Pillar-defined closed structural bay detection; adds solid RCC roof slab (+1 ft).
     * Mutually exclusive switching with zero elevation conflicts.
   - Multi-Floor Management:
     * Add Floor (`+ Add Floor`) with automatic deep cloning of structural axes.
     * Floor-specific state isolation: editing Floor 1 never alters Ground Floor.
     * Floor selector tabs with live wall count, opening count, and pillar indicators.

B. Foundation & Footing Mode (`activeMode === 'foundation'`):
   - Isolated Foundation Footings:
     * Snaps under each RCC column axis or allows custom footing layout.
     * Footing shapes: Isolated Trapezoidal Pad, Step Footing, or Flat RCC Pad.
     * Excavation parameters: Trench Length, Width, Depth (e.g. 5'×5'×5').
     * PCC Base: 1:4:8 Plain Cement Concrete mud mat layer (thickness: 3" - 6").
     * RCC Footing Pad: Trapezoidal depth ($D_1$ bottom pad + $D_2$ sloped taper).
     * Steel Rebar Mat: Bidirectional orthogonal mesh ($X$-bars and $Y$-bars, e.g. 10mm @ 150mm c/c).
     * Column Starter Stub: Rebar starter dowels extending from footing base up to plinth level.
     * Backfilling volume computation (Excavation volume minus concrete footings & stubs).

C. Plastering Mode (`activeMode === 'plaster'`):
   - Surface-by-surface inspection and customized plaster configuration:
     * Inner Masonry Wall Plaster (Standard 12mm, 1:6 cement-sand mortar).
     * Outer Masonry Wall Plaster (Standard 15mm/20mm, 1:4 waterproof cement-sand mortar).
     * RCC Column Face Plaster (Standard 6mm/10mm, 1:4 mortar).
     * RCC Side Beam Face Plaster (Standard 6mm/10mm, 1:4 mortar).
     * Ceiling / Soffit Plaster (Standard 6mm, 1:3/1:4 mortar).
   - "Apply Standard Plaster" 1-click preset setup for rapid estimation.
   - Individual wall overrides (e.g., disable outer plaster for party walls sharing adjacent property).

[MODULE 2] REAL-TIME 3D WEBGL VISUALIZATION ENGINE
(Location: src/components/3d/VisualEstimator3D.tsx)
--------------------------------------------------------------------------------
Built on Three.js and React Three Fiber, the 3D visualizer renders a photorealistic,
structural digital twin of the building project:

A. High-Performance Instanced Brick Rendering:
   - Uses `THREE.InstancedMesh` to render individual masonry bricks with stretcher bond joints.
   - Supports thousands of bricks in real-time at 60 FPS without DOM or WebGL overhead.
   - Dynamic mortar joints (horizontal and vertical thickness).

B. Zero Masonry Collision Architecture:
   - `splitWallByPillars`: Walls intersecting RCC columns are algorithmically split into sub-segments.
   - Masonry stops flush at concrete column faces with 0.00% physical intersection.
   - 3D Collision Exclusion Debug mode highlights bounding boxes to guarantee structural integrity.

C. Additive Multi-Floor Elevation Stacking:
   - Vertical elevation order: Ground Plinth -> Wall Height (10 ft) -> Ring Beam / Slab -> Upper Floor.
   - Exact vertical coordinate continuity: Lower column top elevation ($Y_{\text{top}}$) exactly 
     matches upper column bottom elevation ($Y_{\text{bottom}}$) with $0.00\text{mm}$ gap.

D. Pillar-to-Pillar Horizontal Beam Framing:
   - `detectPillarToPillarBeams`: Automatically detects and renders continuous horizontal RCC beams 
     connecting adjacent pillars along both perimeter and internal grid lines.

E. Closed Structural Bay Detection:
   - `detectClosedStructuralBays`: Detects enclosed rectangular bays formed by 4 surrounding pillars.
   - Renders modular RCC slab panels framed neatly within column faces.

F. Exposed Rebar Inspection Mode (X-Ray Visualization):
   - Translucent Concrete Rendering: Concrete shells render at `renderOrder={1}`, `opacity: 0.20`, 
     `transparent: true`, `depthWrite: false`, eliminating shadow artifacts and clipping.
   - High-Contrast Metallic Steel Rebar: Rebar rendered at `renderOrder={10}`, `metalness: 0.95`, 
     `roughness: 0.15` in dark steel (`#0f172a`).
   - Independent Dual Controls in Scene Elements:
     * `Show Pillar Rebar Cage`: Displays vertical main bars (4, 6, or 8 rods), closed stirrup ties, 
       starter dowel projections, and 3-tier beam-column joint confining ties.
     * `Show Roof/Slab Rebar`: Displays 2-way orthogonal rebar mesh (Main bars along width, 
       Distribution bars along depth) centered at the exact mid-plane of the slab thickness.
     * `Show Foundation`: Displays 3D concrete isolated footings, column stubs, and soil bed.
     * `Show Footing Rebar`: Displays 3D bottom steel mat and starter column rebar cages.
     * `Show Inner / Outer / RCC Plaster`: Displays rendered plaster skin layers over wall and column surfaces.

G. Scene Elements & Camera Controls:
   - Scene Elements drawer for individual toggles (Internal walls, Solid pillars, Pillar rebar, 
     Slab rebar, Ring beams, Full roof, Foundation, Wireframe, Labels).
   - Camera Presets: 3D Free Orbit, Isometric View, Front View, Side View, Top View, Reset Camera.

[MODULE 3] CIVIL ENGINEERING MATHEMATICAL CALCULATION ENGINE
(Location: src/lib/brickCalculator.ts)
--------------------------------------------------------------------------------
A comprehensive civil engineering calculation library running on strict mathematical 
and volumetric principles:

A. Brick Masonry Estimation:
   - Gross Wall Volume = Length × Height × Thickness.
   - Opening Deductions = Sum of (Door/Window Width × Height × Wall Thickness).
   - Pillar Deductions = Volume occupied by concrete columns inside wall footprint.
   - Net Wall Volume = Gross Volume - Opening Deductions - Pillar Deductions.
   - Nominal Brick Volume = $(L + t_{\text{mortar}}) \times (W + t_{\text{mortar}}) \times (H + t_{\text{mortar}})$.
   - Base Brick Count = Net Wall Volume / Nominal Brick Volume.
   - Final Brick Count = Base Brick Count × $(1 + \text{Wastage} / 100)$.
   - Recommended Purchase = $\text{Math.ceil}(\text{Final Brick Count})$.
   - Wet Mortar Volume = Net Wall Volume - (Base Brick Count × Actual Brick Volume).
   - Dry Mortar Volume = Wet Mortar Volume × 1.33 (33% dry bulking factor).
   - Cement Requirement = Dry Mortar Volume × $(1 / (\text{Cement Parts} + \text{Sand Parts})) / 0.0347 \text{ m}^3\text{/bag}$.
   - M-Sand Requirement = Dry Mortar Volume × $(\text{Sand Parts} / \text{Total Parts}) \times 35.3147 \text{ CFT/m}^3$.

B. Plastering Estimation (Conforming to IS 1200 Opening Deductions):
   - Net Plaster Area computed per surface (Inner Walls, Outer Walls, RCC Columns, Beams, Ceiling).
   - IS 1200 Code Opening Deduction Rules:
     * Opening Area < 0.5 m² : No deduction, no jamb addition.
     * Opening Area between 0.5 m² and 3.0 m² : 50% deduction for one face, jambs included.
     * Opening Area > 3.0 m² : 100% deduction on both faces, jambs added separately.
   - Wet Plaster Volume = Net Plaster Area × Plaster Thickness (e.g. 12mm = 0.012m).
   - Dry Plaster Volume = Wet Volume × 1.30 (30% bulking & joint filling factor).
   - Material Breakdown: Cement bags (50kg) and Plastering M-Sand (CFT & m³).

C. RCC Structural Framing Estimation:
   - Concrete Mix Grades:
     * M20 (1 : 1.5 : 3) -> Total parts = 5.5, Dry factor = 1.54.
     * M15 (1 : 2 : 4) -> Total parts = 7.0, Dry factor = 1.54.
     * M10 (1 : 3 : 6) -> Total parts = 10.0, Dry factor = 1.54.
   - Pillar / Column Quantities:
     * Concrete Volume = Pillar Width × Depth × Height × Pillar Count.
     * Longitudinal Main Rebar: Total length × $(D^2 / 162) \text{ kg/m}$.
     * Lateral Stirrups: Perimeter tie length × Number of ties × $(D_{\text{tie}}^2 / 162) \text{ kg/m}$.
     * Binding Wire: 10 - 12 kg per metric tonne of steel.
     * Concrete Cover Blocks: 4 - 6 blocks per column.
   - Ring Beams & Floor Beams:
     * Beam Concrete Volume = Total Span Length × Beam Width × Beam Depth.
     * Top & Bottom Reinforcement bars + Stirrup rings at 150mm spacing.
   - Roof & Floor Slabs:
     * Concrete Volume = Bay Area × Slab Thickness.
     * 2-Way Reinforcement: Main steel (10mm @ 150mm c/c) + Distribution steel (8mm @ 150mm c/c).
   - Aggregate Breakdown:
     * Cement (50kg bags @ 0.0347 m³/bag).
     * M-Sand (CFT & m³).
     * 20mm Blue Metal Jalli / Coarse Aggregate (CFT & m³).

D. Foundation & Footing Estimation:
   - Earthwork Excavation = Sum of (Pit Length × Pit Width × Pit Depth) for all footings.
   - PCC 1:4:8 Base = Footing Pit Area × PCC Thickness (0.10m - 0.15m).
   - RCC Footing Concrete = Trapezoidal / Pad volume per footing.
   - Footing Steel Mat = Orthogonal rebar length × $(D^2 / 162)$.
   - Column Starter Dowel Stubs = Vertical starter bars into column + Ties.
   - Backfilling Volume = Earth Excavation - Total Concrete Substructure.

E. Labor Costing & Productivity Analysis:
   - Mason productivity: 450 - 550 bricks laid per day per mason.
   - Helper productivity: 650 - 750 bricks mixed and transported per day per helper.
   - Total Days Required = Total Bricks / (Mason Count × Mason Daily Productivity).
   - Total Masonry Labor Cost = (Masons × Daily Wage + Helpers × Daily Wage) × Total Days.
   - RCC Structural Labor Cost = Total RCC Concrete Volume (m³) × RCC Labor Rate (₹/m³).

[MODULE 4] CLOUD PROJECT PERSISTENCE & HISTORY MANAGEMENT
(Location: src/lib/projectStorage.ts, SaveProjectModal.tsx, ProjectHistoryModal.tsx)

Enables builders, contractors, and users to save complete 3D construction plans, 
store them in the database, and retrieve them at any time:

A. PostgreSQL Database Model (`SavedProject` in Prisma):
   - Stores project name, dimensions, floor count, total bricks, total cost, cement bags, 
     and sand volume.
   - Serializes complete 3D building model (walls, pillars, openings, beams, footings, plaster) 
     as JSON (`modelData`).
   - Serializes calculator settings, brick type specification, and calculation results.

B. REST API Handlers:
   - `GET /api/projects` : Lists all saved project summaries with fast indexed queries.
   - `POST /api/projects` : Validates, sanitizes, and creates new saved project records.
   - `GET /api/projects/[id]` : Retrieves full project record with complete 3D JSON data.
   - `DELETE /api/projects/[id]` : Deletes saved project from database.

C. Dual-Storage & Offline Fallback:
   - If PostgreSQL is connected, projects are synchronized with the cloud.
   - If `DATABASE_URL` is unconfigured or network is offline, automatically saves to browser 
     `localStorage` (`brick_factory_saved_projects_v1`) without crashing or losing data.
   - Project History Modal displays badge: "Cloud Database Connected" or "Browser Local Cache".

D. Project History Management UI:
   - Search saved projects by name.
   - Filter by date, floor count, or brick requirement.
   - 1-Click "Load Project" imports walls, pillars, footings, and settings directly into the active 3D scene.
   - Delete confirmation dialog.

5. MATHEMATICAL FORMULAS & CIVIL ENGINEERING REFERENCE
================================================================================

1. Brick Masonry Equations:
   - Gross Wall Volume:
     $$V_{\text{gross}} = L \times H \times T$$
   - Total Deductions:
     $$V_{\text{deductions}} = \sum (W_{\text{opening}} \times H_{\text{opening}} \times T) + \sum (W_{\text{pillar}} \times D_{\text{pillar}} \times H)$$
   - Net Masonry Volume:
     $$V_{\text{net}} = V_{\text{gross}} - V_{\text{deductions}}$$
   - Nominal Brick Volume (with 10mm mortar):
     $$V_{\text{nominal}} = (L + 0.010\text{m}) \times (W + 0.010\text{m}) \times (H + 0.010\text{m})$$
   - Base Brick Count:
     $$N_{\text{base}} = \frac{V_{\text{net}}}{V_{\text{nominal}}}$$
   - Final Bricks with Wastage:
     $$N_{\text{final}} = N_{\text{base}} \times \left(1 + \frac{\text{Wastage}\%}{100}\right)$$
   - Recommended Purchase:
     $$N_{\text{purchase}} = \lceil N_{\text{final}} \rceil$$
   - Wet Mortar Volume:
     $$V_{\text{wet mortar}} = V_{\text{net}} - (N_{\text{base}} \times L \times W \times H)$$
   - Dry Mortar Volume (33% bulking):
     $$V_{\text{dry mortar}} = V_{\text{wet mortar}} \times 1.33$$
   - Cement Bags Required (Mortar Mix 1 : M, e.g. 1:5):
     $$\text{Cement Bags} = \frac{V_{\text{dry mortar}} \times \frac{1}{1 + M}}{0.0347 \text{ m}^3\text{/bag}}$$
   - M-Sand Volume Required:
     $$\text{Sand CFT} = V_{\text{dry mortar}} \times \frac{M}{1 + M} \times 35.3147$$

2. Plastering Equations (Conforming to IS 1200):
   - Net Plaster Area:
     $$A_{\text{net}} = A_{\text{wall surface}} - A_{\text{deductions (IS 1200)}}$$
   - Wet Plaster Volume (e.g. 12mm thickness):
     $$V_{\text{wet plaster}} = A_{\text{net}} \times 0.012\text{m}$$
   - Dry Plaster Volume (30% joint filling & bulking factor):
     $$V_{\text{dry plaster}} = V_{\text{wet plaster}} \times 1.30$$
   - Cement Bags for Plaster:
     $$\text{Cement Bags} = \frac{V_{\text{dry plaster}} \times \frac{1}{1 + M_{\text{plaster}}}}{0.0347}$$
   - M-Sand for Plaster:
     $$\text{Sand CFT} = V_{\text{dry plaster}} \times \frac{M_{\text{plaster}}}{1 + M_{\text{plaster}}} \times 35.3147$$

3. RCC Structural Framing Equations:
   - Dry Concrete Volume Conversion Factor:
     $$V_{\text{dry concrete}} = V_{\text{wet concrete}} \times 1.54$$
   - M20 Mix Ratio (1 : 1.5 : 3, Total Parts = 5.5):
     $$\text{Cement (m}^3\text{)} = V_{\text{dry}} \times \frac{1}{5.5} \implies \text{Bags} = \frac{\text{Cement m}^3}{0.0347}$$
     $$\text{M-Sand (CFT)} = V_{\text{dry}} \times \frac{1.5}{5.5} \times 35.3147$$
     $$\text{20mm Blue Metal Jalli (CFT)} = V_{\text{dry}} \times \frac{3.0}{5.5} \times 35.3147$$
   - Steel Rebar Unit Weight Formula:
     $$\text{Weight (kg/m)} = \frac{D^2}{162} \quad (D \text{ in mm})$$
   - Total Steel Weight:
     $$\text{Steel Weight (kg)} = \sum \left(\text{Bar Length} \times \frac{D^2}{162}\right) \times (1 + \text{Wastage Factor})$$
   - Binding Wire Required:
     $$\text{Binding Wire (kg)} = \text{Total Steel (tonnes)} \times 10\text{ to }12\text{ kg}$$

4. Foundation & Footing Equations:
   - Pit Excavation Volume:
     $$V_{\text{excavation}} = L_{\text{pit}} \times W_{\text{pit}} \times D_{\text{pit}}$$
   - PCC 1:4:8 Mud Mat Base:
     $$V_{\text{PCC}} = L_{\text{pit}} \times W_{\text{pit}} \times T_{\text{PCC}}$$
   - Trapezoidal Footing Volume:
     $$V_{\text{footing}} = \left(L_{\text{base}} \times W_{\text{base}} \times d_1\right) + \frac{d_2}{3}\left(A_1 + A_2 + \sqrt{A_1 \times A_2}\right)$$
   - Backfilling Volume:
     $$V_{\text{backfill}} = V_{\text{excavation}} - (V_{\text{PCC}} + V_{\text{footing}} + V_{\text{stub column}})$$

5. Grand Total Project Cost Estimation:
   $$\text{Grand Total Cost} = \text{Cost}_{\text{Masonry}} + \text{Cost}_{\text{Plaster}} + \text{Cost}_{\text{RCC}} + \text{Cost}_{\text{Foundation}} + \text{Cost}_{\text{Labour}} + \text{Cost}_{\text{Extras}}$$

6. DATABASE SCHEMA & DATA MODELS (Prisma PostgreSQL)
================================================================================

Defined in `prisma/schema.prisma`:

1. User Model:
   - Fields: id (String, CUID), email (Unique), password, name, role (Role: CUSTOMER, ADMIN, STAFF), 
     createdAt, updatedAt.
   - Relations: orders, cart, reviews, savedProjects.

2. Product Model:
   - Fields: id (String, CUID), name, code (Unique), description, price (Float), stock (Int), 
     minStock (Int), material, strength, categoryId, createdAt, updatedAt.
   - Relations: category, images, cartItems, orderItems, reviews.

3. Category Model:
   - Fields: id (String, CUID), name (Unique), description.
   - Relations: products.

4. ProductImage Model:
   - Fields: id, url, productId.
   - Relations: product.

5. Cart & CartItem Models:
   - Cart: id, userId (Unique), createdAt, updatedAt.
   - CartItem: id, cartId, productId, quantity, relations to Cart and Product.

6. Order & OrderItem Models:
   - Order: id, userId, status (OrderStatus: PENDING, CONFIRMED, MANUFACTURING, READY, DELIVERING, 
     DELIVERED, CANCELLED), totalAmount, paymentStatus (PaymentStatus: PENDING, PAID, FAILED, REFUNDED), 
     createdAt, updatedAt.
   - OrderItem: id, orderId, productId, quantity, price.

7. Review Model:
   - Fields: id, rating (1-5), comment, userId, productId, createdAt.
   - Relations to User and Product.

8. SavedProject Model (Primary Model for Cloud 3D Estimation Persistence):
   - Fields:
     * id             : String (@id @default(cuid()))
     * userId         : String? (Optional relation to User)
     * name           : String (Project title)
     * totalBricks    : Int (Calculated brick requirement)
     * totalCost      : Float (Grand total estimated budget in ₹)
     * cementBags     : Float? (Total 50kg cement bags)
     * sandVolumeCft  : Float? (Total M-Sand in CFT)
     * buildingLength : Float (Footprint length)
     * buildingWidth  : Float (Footprint width)
     * buildingUnit   : String (@default("ft"))
     * floorsCount    : Int (@default(1))
     * modelData      : Json (Full 3D BuildingModel tree: floors, walls, openings, pillars, footings, plaster)
     * settingsData   : Json? (CalculatorSettings configuration)
     * brickTypeData  : Json? (Selected BrickSpecification)
     * estimationData : Json? (CalculationResult snapshot)
     * createdAt      : DateTime (@default(now()))
     * updatedAt      : DateTime (@updatedAt)
     * user           : User? (Relation onDelete: Cascade)

7. REST API SPECIFICATIONS
================================================================================

1. GET /api/projects
   - Description : Retrieves list of all saved project summaries for the Project History Modal.
   - Response    : `{ success: true, projects: SavedProjectSummary[] }`
   - Omission    : Excludes heavy `modelData` JSON for high-speed indexing.

2. POST /api/projects
   - Description : Saves a new 3D building project to PostgreSQL.
   - Request Body:
     `{ name, modelData, totalBricks, totalCost, cementBags, sandVolumeCft, buildingLength, buildingWidth, buildingUnit, floorsCount, settingsData, brickTypeData, estimationData, userId? }`
   - Response    : `{ success: true, message: string, project: SavedProject }`
   - Status 503  : Returns friendly notice if `DATABASE_URL` is not yet configured, allowing LocalStorage fallback.

3. GET /api/projects/[id]
   - Description : Retrieves a single saved project including full 3D `modelData` JSON.
   - Response    : `{ success: true, project: SavedProject }`

4. DELETE /api/projects/[id]
   - Description : Deletes a saved project by ID from PostgreSQL.
   - Response    : `{ success: true, message: "Project successfully deleted from database." }`

5. POST /api/bulk-orders
   - Description : Handles B2B quotation inquiry form submissions and dispatches emails via Nodemailer.
   - Request Body: `{ name, email, phone, company, quantity, location, message }`
   - Response    : `{ success: true, message: "Inquiry received successfully." }`

8. STEP-BY-STEP INSTALLATION & RUN GUIDE

[Prerequisites]
- Node.js (v18.18+ or v20+ recommended)
- npm, yarn, or pnpm
- PostgreSQL database instance (Neon Serverless PostgreSQL, Supabase, or local PostgreSQL)

[Step 1: Clone or Navigate to Project]
cd "d:\brick-factory"

npm install

[Step 3: Environment Configuration]
Create or verify `.env` file in the project root:
```env
# PostgreSQL Database Connection String (e.g. Neon Serverless or Local)

# SMTP Email Configuration (Nodemailer)
```
